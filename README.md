# 🎓 School Management System — Yasin School

Nidaam maamul oo dhamaystiran oo loogu talagalay Dugsiga Yasin.

## 📋 Sifooyinka (Features)

- 🏠 Dashboard
- 👨‍🎓 Students (Add / Edit / Delete / Search)
- 👩‍🏫 Teachers
- 📚 Classes
- 📖 Subjects
- 📝 Attendance
- 📊 Exams & Results
- 💰 Fees
- 📅 Timetable
- 📢 Announcements
- 👤 Users / Admin
- 🔐 Login & Authentication
- 📈 Reports
- ⚙️ Settings

## 🛠️ Technology

- **Frontend:** React + Tailwind CSS + JavaScript
- **Backend:** Node.js ama Python Flask (mar dambe)
- **Database:** SQLite → MySQL/PostgreSQL (mar dambe)
- **Hosting:** GitHub + Vercel/Netlify
